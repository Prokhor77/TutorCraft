# TutorCraft Studio — дизайн-система (из Google Stitch)

Источник: проект Stitch «Платформа Курсов для Репетиторов» (id 2790370855294476224), дизайн-система «TutorCraft Studio».
Экраны в проекте: «Медиатека и каталог материалов» (desktop), «Конструктор курса / тестов» (desktop), 5 мобильных экранов
с нижней навигацией (Курс · Тесты · Прогресс · Медиа · Профиль).

## Характер
«Boutique tactile minimalism» для репетиторов: не «серая админка», а мастерская. Пилюли, мягкие тени с фиолетовым оттенком,
тактильные карточки, выразительные заголовки. Violet — фокус и действия, Emerald — выполнено/опубликовано/сохранено,
Amber — черновик/требует проверки/подсказки, Slate — нейтральные границы и метаданные.

## Типографика
- Заголовки: **Bricolage Grotesque** — xl 40/48 700 (-0.02em; mobile 30/38), lg 32/40 600 (mobile 24/32), md 22/28 600, sm 18/24 600.
- Текст и подписи: **Work Sans** — body-lg 16/26, body-md 14/22, body-sm 12/18; label-lg 14/20 600, label-md 12/16 600 (+0.02em), label-sm 10/14 600 (+0.04em, uppercase для бейджей/шорткатов).

## Форма, отступы, глубина
- Радиусы: sm 0.5rem, DEFAULT 1rem (поля ввода), md 1.5rem, lg 2rem (карточки вопросов, дропзона), xl 3rem, full (кнопки, чипы, пункты дерева).
- Отступы: xs 4, sm 8, md 16, lg 24, xl 36; gutter 20, margin 28. Дерево модулей — отступ 16px на уровень; карточки — padding 24, gap 16.
- Тени: L1 карточка `0 2px 8px -2px rgba(15,23,42,.04), 0 1px 3px rgba(15,23,42,.02)` + граница `rgba(99,102,241,.08)`;
  L2 hover/фокус `0 8px 24px -4px rgba(99,102,241,.12), 0 2px 6px -1px rgba(99,102,241,.06)` + граница `rgba(99,102,241,.3)`;
  L3 drag `scale(1.02)`, `0 20px 32px -8px rgba(15,23,42,.16), 0 8px 16px -4px rgba(99,102,241,.18)`.
- Стекло: липкие панели действий — `backdrop-filter: blur(12px); background: rgba(255,255,255,.82)` + нижняя линия.

## Компоненты
- Кнопки: Primary — pill, заливка violet, Work Sans 600, hover `translateY(-1px)` + свечение; Secondary — ghost-pill `rgba(99,102,241,.08)` + текст violet; Success — emerald («Опубликовать урок», «Сохранить изменения»).
- Поля: радиус 1rem, граница 1.5px `#e2e8f0`, фокус — граница violet + кольцо 4px `rgba(99,102,241,.15)`; плейсхолдеры дружелюбные («Введите формулировку вопроса или темы…»).
- Карточка вопроса: белая, радиус 2rem, ручка перетаскивания слева, иконка типа («Один выбор», «Развёрнутый ответ»), индикатор баллов.
- Узлы дерева модулей: pill-строки со стрелкой сворачивания, зелёные галочки выполнения, акцентная полоса активного.
- Radio: кольцо с мягким «bounce», выбранное — violet-точка; Checkbox — радиус 0.5rem, анимация галочки.
- Дропзона: пунктир `rgba(99,102,241,.3)`, радиус 2rem, фон `#f8f9fe`, текст «Перетащите аудио, видео или материалы урока сюда» + кнопка выбора файла.

## Раскладка
- Desktop ≥1280: верхняя шапка с логотипом, хлебными крошками и pill-вкладками разделов (Конструктор курса · Конструктор тестов · Медиатека · Аналитика), справа «Предпросмотр» и primary «Опубликовать курс».
  Рабочая область — 3 панели: дерево курса слева 280–340px, холст по центру (max 860px), инспектор справа 320px.
- Tablet 768–1279: инспектор — выезжающая панель, дерево — иконки.
- Mobile <768: одна колонка; нижняя навигация; в конструкторе — сегменты «Конструктор / Структура / Предпросмотр».
