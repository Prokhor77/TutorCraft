Задача 3. Треугольник ABC, сторона a=7, b=5, cos(C)=1/5... Шаг 1: Верно ✓

1) По теореме косинусов для стороны c:

c² = a² + b² - 2ab · cos(C)

c² = 49 + 25 - 2·7·5·(0.2) = 74 - 14 = 60

⇒ c = 2√15   (найдено корректно)

2) Радиус описанной окружности R:

R = c / (2 · sin(C))

sin²(C) = 1 - cos²(C) = 1 - 1/25 = 24/25

sin(C) = - (2√6)/5   ← Ошибка в знаке!

R = (2√15) / (2 · (2√6)/5) = (5√10)/4

info Внимание:
Угол С в треугольнике острый/тупой, но sin(C) всегда > 0! Знак минус невозможен.
