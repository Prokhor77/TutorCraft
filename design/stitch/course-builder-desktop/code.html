В задачах 16 (планиметрия повышенной сложности) применение обобщенной теоремы синусов позволяет выразить радиус описанной окружности $R$, избегая громоздких дополнительных построений.

bookmark_star Опорная теорема (критерий оценивания №2) Шпаргалка
$\frac{a}{\sin \alpha} = \frac{b}{\sin \beta} = \frac{c}{\sin \gamma} = 2R$

Примечание: Обязательно указывать в бланке №2, к какому именно треугольнику применяется соотношение!

Для нахождения косинуса угла при трех известных сторонах используйте следствие из теоремы косинусов: $\cos \alpha = \frac{b^2 + c^2 - a^2}{2bc}$. Если $\cos \alpha < 0$, угол является тупым.
