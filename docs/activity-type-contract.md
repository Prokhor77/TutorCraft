# Как добавить новый тип элемента курса (FR-EXT-01)

1. Добавьте значение в `courses.ItemType` (ключ в нижнем регистре) — единственное изменение ядра.
2. В своём модуле реализуйте `courses.spi.ActivityType` как Spring-бин:
   - `defaults()` — настройки по умолчанию (элемент создаётся по одному названию, UX-02);
   - `validate(settings)` — валидация и нормализация, ошибки с полями `settings.<name>` (DATA-04);
   - `dueAt/openAt/closeAt` — ключевые даты для «Моих задач», календаря и напоминаний;
   - `learnerView(settings)` — скрыть от студента служебные поля (ключи ответов и т.п.);
   - `referencedFileIds(settings)` — файлы, которые нужно привязать к элементу.
3. Если у активности есть статус для студента — реализуйте `courses.spi.ItemStatusProvider`; если есть работы на проверку — `gradebook.spi.GradingQueueSource`; если выставляются оценки — подпишитесь на `CourseEvents.ItemChanged` и вызывайте `GradebookApi.ensureGradeItem/recordGrade`.
4. Выполнение: публикуйте доменное событие, на которое подпишется модуль `progress` (или расширьте его правило).
5. Данные активности храните в своих таблицах/коллекциях (свой номер миграции Flyway) и реализуйте `courses.spi.CourseDataOwner`, если данные учащихся должны удерживать курс от физического удаления (ADR-010).
6. Во фронтенде добавьте страницу элемента в `apps/web/src/features/items/<type>` и тип в палитру «+».
