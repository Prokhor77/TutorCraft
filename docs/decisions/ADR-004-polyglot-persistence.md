# ADR-004: PostgreSQL + MongoDB
Статус: принято

**Решение.** Граница: всё, что участвует в правах, деньгах, оценках, отчётах и требует ACID/join — PostgreSQL. Гибкие по схеме структуры (модули/элементы курса с настройками по `ActivityType`, блочные документы, вопросы с версиями) — MongoDB.
Ссылки между хранилищами — по UUID (`items._id` ↔ `submissions.item_id`). Консистентность: Mongo-документ создаётся первым; при сбое записи в PostgreSQL — компенсация (мягкое удаление). Метаданные курса дублируются в PostgreSQL как источник истины для прав и каталога.

**Риски.** Нет распределённых транзакций → операции, затрагивающие оба хранилища, идемпотентны и повторяемы.
