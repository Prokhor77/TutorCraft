# ADR-012: Монетизация — только подписка школы, без продажи курсов
Статус: принято · 2026-09-29 · заменяет часть ADR-002 про `FR-ENROL-09`

**Контекст.** ADR-002 поднял в P0 платную запись на курс (цена курса, заказы, YooKassa/Stripe, уведомление
«Новая продажа»). Модель продукта поменялась: платит только репетитор (школа) — фиксированную сумму за доступ к
платформе. Ни платформа, ни репетитор через платформу денег с учеников не получают.

**Решение.**
- Единственный платёж — подписка школы (`billing.SubscriptionApi`, контракт §13): один тариф, одинаковый
  функционал, сроки 1 месяц — 30 USD, 3 месяца — 75 USD, 1 год — 150 USD; 14 дней пробного периода.
  Количество курсов и учеников не ограничено.
- Без активной подписки школа работает «только на чтение» (нельзя создавать, копировать и публиковать курсы);
  ученики продолжают учиться.
- Курсы для учеников бесплатны: цены курса нет, запись — вручную, по ссылке-приглашению, импортом или
  самозаписью (при необходимости — по кодовому слову).
- Удалено: `PUT /courses/{id}/price` и поле `price` в Course/CourseCard/PublicCourse, заказы
  (`POST /courses/{id}/orders`, `GET /orders/{id}`, `GET /billing/orders`, `POST /billing/fake/{orderId}/pay`),
  вебхуки провайдеров `/billing/webhooks/{provider}`, `PaymentGateway` (Fake/YooKassa/Stripe), событие
  `OrderPaid` и исходящий вебхук `order.paid`, категория уведомлений `sale`, код `enrollment.payment_required`,
  страницы `/checkout/*` и «Админка → Продажи».
- `PAYMENT_PROVIDER` остаётся только для подписки (пока `fake` — мгновенная активация). Реальный провайдер
  подключается отдельным портом оплаты подписки, когда он понадобится (YAGNI: старый порт был заточен под заказы).

**Схема данных (expand/contract, NFR-REL-03).** В этом релизе код перестаёт читать и писать `courses.price_*`,
`orders`, `payment_events`; схема не меняется, чтобы откат на предыдущий образ оставался безопасным.
Contract-миграция (billing, следующий свободный номер) удаляет `orders`, `payment_events`,
`courses.price_amount_minor`, `courses.price_currency` и ограничение `courses_price_complete` в следующем релизе.
Историческое значение `enrollments.method = 'payment'` остаётся допустимым (старые записи).

**Последствия.** Курсы, у которых раньше была цена, становятся доступны по своим настройкам самозаписи: если
самозапись включена без кодового слова — записаться может любой, кто видит лендинг. Строки настроек уведомлений
с категорией `sale` и вебхуки, подписанные на `order.paid`, просто игнорируются.
