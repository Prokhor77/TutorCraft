# ADR-003: Сессии и токены
Статус: принято

**Решение.** Access JWT (HS256 для MVP — ключ из env `JWT_SECRET`, ≥ 32 байта; переход на RS256 + JWKS при появлении внешних потребителей) со сроком 15 мин, передаётся в заголовке `Authorization`. Refresh — непрозрачный случайный токен 256 бит, в БД только SHA-256-хеш, cookie `tc_refresh` (httpOnly, Secure, SameSite=Strict, Path=/api/v1/auth). Ротация с семействами: повторное предъявление отозванного токена отзывает семейство.

**Почему не cookie для access.** Нет CSRF-поверхности для API; SSR-страницы, требующие авторизации, не нужны (SSR только для публичных витрин).
